## SIGKILL Fix
Root cause: OpenClaw exec tool defaults to 15s timeout. Commands exceeding 15s (like `openclaw status`, `openclaw gateway restart`, long `openclaw message send`) get SIGKILLed. No config key to change the default; timeout must be passed per-tool-call.

Fixes applied:
- Morning-summary cron (`action-items:morning-summary`): switched from `ollama/llama3.2:3b` to `google/gemini-2.5-flash`, timeout 120s. Was taking 273s with llama3.2.
- PM-checkin cron (`action-items:pm-checkin`): switched from `ollama/llama3.2:3b` to `google/gemini-2.5-flash`, timeout 60s.
- KB refresh cron (`support_lead_kb_refresh_daily`): increased timeout to 300s (was already using gemini-2.5-flash but had a recent error).

Self-fix: always pass `timeout` >= 60 for `openclaw` CLI commands, >= 30 for other commands when calling exec. The 15s default kills anything that takes a moment to start up.
