
## Step 2, create the Dockerfile
Run:

```bash
cat > ~/hermes-compose/Dockerfile <<'EOF'
FROM --platform=linux/amd64 nousresearch/hermes-agent
USER root
RUN apt-get update && apt-get install -y docker.io && rm -rf /var/lib/apt/lists/*
EOF
```

This creates the custom Hermes image definition with Docker CLI included.

---

## Step 3, create the docker-compose.yml file
Run:

```bash
cat > ~/hermes-compose/docker-compose.yml <<'EOF'
services:
  hermes:
    build:
      context: .
      dockerfile: Dockerfile
    image: hermes-agent-with-docker:latest
    container_name: hermes
    platform: linux/amd64
    command: gateway
    ports:
      - "8080:8080"
    volumes:
      - /Users/duaneleitch/.hermes:/opt/data
      - /var/run/docker.sock:/var/run/docker.sock
    restart: unless-stopped
EOF
```

This defines the persistent Hermes container setup.
