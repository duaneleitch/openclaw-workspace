# Duane Action Register

**Purpose:** A single, Duane-owned working list of outcomes that require action.  
**Scope:** Duane's actions only. Do not add actions owned solely by another person or team.  
**Daily summary:** Lists only items with `Status: Open` and links to this register.

## Operating Rules

1. Capture one outcome per row, starting with a clear action verb.
2. Use a stable ID (`A-001`, `A-002`, and so on). Never renumber an existing item.
3. Keep only actionable work in **Open Actions**. Move blocked work to **Pending Actions** with a specific dependency and next review date.
4. Use `P1` for urgent or materially time-sensitive work, `P2` for important planned work, and `P3` for useful but non-urgent work.
5. A due date is a real commitment, not a wish. Leave it blank when no commitment exists.
6. Update **Next Step** and **Last Reviewed** whenever an item changes. Move completed work to the monthly archive, rather than keeping it in this working register.
