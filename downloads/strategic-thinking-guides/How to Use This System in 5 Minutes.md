# How to Use This System in 5 Minutes

## What This Is

This system helps you go from a fuzzy strategic problem to a clear, executive-ready output faster.

You do not need to read everything.

## The Fastest Way to Use It

### 1. Write the question in one sentence
Example:
- How should we improve retention in our mid-market SaaS segment without raising support cost?

### 2. Pick one main asset
Use one of these depending on the situation:
- [[Pack Selection Decision Tree]]
- [[Quick Start Paths]]
- [[Navigation by Audience]]
- [[Navigation by Output Type]]

### 3. Add only a few supports
Usually enough:
- 1 main asset
- 1 worked example
- 1 field template

### 4. Draft the output
Use a field template or starter kit to turn the thinking into something usable.

### 5. Check quality
Before sending it, compare against:
- [[Gold Standard Output Library]]
- [[Strategy Output Scorecards]]

## Rule of Thumb

Do not overbuild.

For most work:
- 1 primary asset
- 1 to 3 supporting assets
- 1 template
- 1 quality check

That is enough.
