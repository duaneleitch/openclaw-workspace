# Strategic Thinking System User Guide

## Overview

The Strategic Thinking system is a practical strategy toolkit.

It is designed to help you move from an unclear strategic question to a clear, usable, executive-ready output without starting from scratch every time.

The system includes:
- strategy packs
- playbooks
- starter kits
- worked examples
- field templates
- role guides
- industry overlays
- live-use kits

Use it when you need to:
- clarify a strategic problem
- choose among competing priorities
- prepare an executive or board recommendation
- design a roadmap
- improve the quality of strategic thinking and communication

## Who This Is For

This system is useful for:
- executives
- functional leaders
- strategists
- operators
- chiefs of staff
- transformation leaders

## The Simplest Way to Use the System

For most strategy work, follow this sequence:

### Step 1: Write the question clearly
State the strategic question in one sentence.

Strong example:
- How should we improve retention in our mid-market SaaS segment without increasing support cost?

Weak example:
- Help with retention.

### Step 2: Pick one primary asset
Choose one main asset to anchor the work.

Usually this will be one of these:
- strategy pack
- starter kit
- playbook
- live-use kit

### Step 3: Add a small number of supporting assets
Add 1 to 3 supporting assets only when they materially improve the answer.

Typical support assets:
- one supporting pack
- one worked example
- one field template

### Step 4: Draft the output
Use a template to turn the thinking into a real deliverable.

### Step 5: Quality-check the result
Before finalizing, review against:
- [[Gold Standard Output Library]]
- [[Strategy Output Scorecards]]
- [[Strategic Thinking Quality Rubric]]

## How to Choose the Right Asset Type

### Strategy Pack
Use when you need a domain lens, strategic questions, and output structure.

### Playbook
Use when the situation follows a repeatable pattern such as turnaround, scale-up, or transformation.

### Starter Kit
Use when you want the fastest high-confidence starting point with a recommended stack.

### Worked Example
Use when you want to see what good looks like in structure, tone, and tradeoffs.

### Field Template
Use when you already know the problem and need a fast format for the output.

### Role Guide
Use when the work needs to be shaped for a specific executive or functional leader.

### Industry Overlay
Use when the industry materially changes the buying model, risks, regulatory pressure, or operating logic.

### Live-Use Kit
Use when the work is tied to a recurring operating event such as annual planning, board prep, growth review, or an AI workshop.

## Rules of Good Use

Use these rules to keep the system effective:
- start with a clear question
- use one primary asset
- add only a few supporting assets
- turn the work into a real output
- make tradeoffs explicit
- do not confuse activity with strategy
- do not create a new note if the system already covers the need well

## Common Mistakes to Avoid

Avoid these patterns:
- using too many packs at once
- choosing assets before defining the question
- producing analysis without a recommendation
- skipping tradeoffs and risks
- using an industry overlay when the problem is actually generic
- creating duplicate notes instead of reusing existing ones

## Rule of Thumb

For most work, this is enough:
- 1 primary asset
- 1 to 3 supporting assets
- 1 output template
- 1 quality-check pass
