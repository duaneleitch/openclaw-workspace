# Digest Runbook

## Purpose

Turn newly captured material into reviewable, linked knowledge without rewriting broad shared vault content.

## Pilot Mode

- Process a small, named batch of sources.
- Create or update only source notes and clearly marked draft knowledge notes.
- List proposed links, classifications, decisions, risks, and candidate actions for review.
- Do not move existing Markdown files.
- Do not update action registers unless Duane explicitly requests it.

## Quality Gates

Before automation, confirm for each pilot batch:

1. raw source and metadata are present
2. transcript or extract is linked
3. claims are traceable to a source
4. no duplicate canonical note was created
5. retrieval returns the intended canonical note before raw duplicates

## Future Automation

Once pilot quality is accepted, run a scoped overnight digest in Toronto time and deliver a concise morning brief: sources processed, knowledge created or updated, review items, retrieval anomalies, and candidate actions.
