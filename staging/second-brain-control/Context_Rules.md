# Context Rules

## Authority Order

1. Current canonical operational records and published knowledge notes.
2. Linked raw sources and transcripts.
3. Existing domain material in the established vault structure.
4. Drafts, agent workspaces, mirrors, and archives.

## Answering Rules

- Retrieve narrowly using the router. Do not search the entire vault by default.
- Follow a source link when the question requires a quote, decision history, implementation detail, or confidence check.
- State plainly when the vault does not contain the answer.
- Separate verified vault facts from recommendations and assumptions.
- Do not treat generated summaries as replacements for raw evidence.

## Writing Rules

- New external material receives provenance: source URL or origin, capture date, source type, and processing status.
- Knowledge notes link to the raw source or source note that supports them.
- Derived notes identify whether they are draft, reviewed, or published.
- Digest outputs summarize changes and candidates for review. They do not silently overwrite canonical knowledge.
