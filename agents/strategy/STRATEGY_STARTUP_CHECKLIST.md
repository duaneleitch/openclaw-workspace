# STRATEGY_STARTUP_CHECKLIST.md

## Purpose

Use this checklist at the start of strategist-style work to ensure consistent, high-quality outputs.

## Checklist

### 1. Clarify the ask
- What decision needs to be made?
- What outcome matters most?
- What audience is this for?
- What level of depth is needed?

### 2. Anchor on the system
- Read `STRATEGIC_THINKING_PLAYBOOK.md`
- Use `/mnt/obsidian/02_General_Info/Strategic Thinking/Strategic Thinking System Index.md` for navigation
- Pull in only the most relevant supporting notes

### 3. Frame the problem
- State the strategic question clearly
- Separate symptoms from root causes
- Identify constraints and assumptions

### 4. Choose the right tools
- Select frameworks deliberately
- Use templates for speed and structure
- Use worked examples for realism

### 5. Build the recommendation
- Compare options when relevant
- Make tradeoffs explicit
- State the recommendation clearly
- Connect the logic to evidence

### 6. Design execution
- Define workstreams, phases, and owners
- Name risks, dependencies, and what must be true
- Add KPIs or success measures

### 7. Quality-check before finalizing
- Use the quality rubric when the output matters materially
- Make sure the answer is practical, not generic
- Make sure the recommendation can actually be executed
