## When To Use This Playbook

Use for:
- strategic priorities
- annual and quarterly planning
- transformation roadmaps
- executive decision memos
- operating model design
- initiative sequencing
- tradeoff-heavy recommendations
- strategic narratives and storytelling

## Core Standard

Every strong strategic output should help the user:
- frame the real problem
- understand the context
- assess evidence
- compare options
- make tradeoffs explicit
- choose a direction
- move from strategy to action

## Default Output Structure

When relevant, include:
1. Objective
2. Current state
3. Core problem or opportunity
4. Key insights
5. Options considered
6. Recommendation
7. Tradeoffs
8. Risks and dependencies
9. Execution path
10. Success measures
11. 30/60/90 day plan

## Strategic Thinking Workflow

### Step 1: Frame the Question
Ask:
- What decision needs to be made?
- What problem are we really solving?
- What outcome matters most?
- What constraints are real?

### Step 2: Diagnose the Situation
Clarify:
- current state
- relevant trends
- stakeholder context
- internal constraints
- external pressures

### Step 3: Structure the Problem
Use:
- issue trees
- logic trees
- root cause analysis
- systems thinking

### Step 4: Investigate
Use both:
- quantitative evidence
- qualitative evidence

### Step 5: Generate Strategic Options
For each option, assess:
- likely impact
- effort and complexity
- risks
- dependencies
- timing
- reversibility

### Step 6: Make the Tradeoffs Explicit
Always state:
- what this choice prioritizes
- what it deprioritizes
- what must be true for it to work

### Step 7: Build the Strategic Story
A good strategic narrative explains:
1. what changed
2. why it matters
3. what the evidence shows
4. what choice is recommended
5. why this is the right path
6. how execution will work
7. what success looks like

### Step 8: Convert to Action
Translate strategy into:
- workstreams
- owners
- milestones
- dependencies
- KPIs
- review cadence

## Framework Selection Guide

### If the problem is vague
Use:
- strategic question framing
- logic tree
- root cause analysis

### If the market or environment is changing
Use:
- PEST
- Porter’s Five Forces
- scenario planning

### If execution is the issue
Use:
- systems thinking
- Theory of Constraints
- roadmap review
- premortem

### If prioritization is weak
Use:
- option comparison
- tradeoff analysis
- OKRs
- resource allocation review

### If executive buy-in is needed
Use:
- one-page strategy memo
- executive narrative
- decision memo with options and tradeoffs

## Non-Negotiables

- Do not confuse planning with strategy.
- Do not present a long list of actions without a coherent strategic logic.
- Do not hide tradeoffs.
- Do not rely on internal opinion alone when evidence is needed.
- Do not recommend transformation without accounting for execution capacity.
- Do not overcomplicate the answer when a clear recommendation is possible.

## Quality Check Before Finalizing

Before finishing, ask:
- Is the strategic question clear?
- Is the recommendation actually responsive to that question?
- Are options and tradeoffs visible?
- Are risks and dependencies concrete?
- Is the output practical, not theoretical?
- Could an executive understand the logic quickly?
- Is there a credible path from strategy to action?
- If formally reviewing quality, use `/mnt/obsidian/02_General_Info/Strategic Thinking/Strategic Thinking Quality Rubric.md`.
