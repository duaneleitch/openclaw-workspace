# Output Recipes

Use the smallest format that satisfies the request.

## Standard rewrite

Return:
1. revised text
2. short change summary

Example summary bullets:
- cut filler and inflated phrasing
- made the rhythm less uniform
- kept the original level of formality

## High-risk rewrite

Return:
1. conservative rewrite
2. optional stronger alternative for safe lines only
3. precision note

Example precision note:
- Kept the original scope, qualifiers, and technical terms intact.

## Multiple options

Use when the user asks for alternatives or when one version may trade brevity for warmth.

Return:
- Option 1: tighter and more direct
- Option 2: slightly warmer
- One-line tradeoff note

## Voice-match

When given a sample or target role:
- state the inferred voice briefly
- mirror directness, cadence, and formality
- avoid mimicry that adds facts or personality not supported by the source

## Analysis only

Return four short sections:
- Signals
- Voice
- Risk
- Recommendation

Keep the diagnosis practical. Focus on the few issues most worth fixing.
